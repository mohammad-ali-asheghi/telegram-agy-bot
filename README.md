# بات تلگرام اختصاصی برای Antigravity CLI (Java + Docker)

این پروژه یک برنامه با زبان **Java 17** و به صورت کانتینری (**Docker**) است که به شما امکان می‌دهد بدون نیاز به روشن کردن کامپیوتر شخصی، مستقیماً از طریق تلگرام به سرور خود متصل شده و پرامپت‌های برنامه‌نویسی را به **Google Antigravity CLI (`agy`)** ارسال کنید و نتیجه نهایی را در تلگرام دریافت نمایید.

---

## 🌟 ویژگی‌های کلیدی

- ⚡ **بدون نیاز به پورت باز یا دامنه (Long Polling):** نیاز به هیچ‌گونه Webhook، دامنه یا گواهی SSL ندارد و به راحتی پشت NAT یا فایروال کار می‌کند.
- 🔐 **امنیت بالا (User Authentication):** تنها شناسه‌های کاربری تلگرام مجاز (`ALLOWED_USER_IDS`) امکان ارسال دستور به سرور را دارند.
- 🚀 **اتصال مستقیم SSH به سرور:** اجرای دستورات در شل سرور (`bash -l`) با پشتیبانی از کلید خصوصی SSH (Key) یا رمز عبور (Password).
- 🔄 **پشتیبانی از ادامه گفتگو (Continue Session):** امکان ادامه دادن مکالمه قبلی با فلگ `--continue` (`-c`) یا شروع گفتگوی جدید (`--print`).
- 📂 **مدیریت دایرکتوری کاری:** تغییر مسیر پروژه با `/cd` و مشاهده مسیر فعلی با `/pwd`.
- 💻 **ترمینال زنده و تعاملی سرور (Real Interactive Terminal):**
  - ورود به محیط ترمینال واقعی شل با دستور `/term` یا `/terminal`
  - اجرای هرگونه اسکریپت (Bash, Python, Node, ...) و دستور دلخواه (`ls -la`, `top`, `git`, ...)
  - پشتیبانی از **ورودی‌های تعاملی (stdin)**: امکان پاسخ به پرسش‌های اسکریپت، منوهای شماره‌ای و تأییدیه‌های `[y/N]`
  - دارای **کیبورد شیشه‌ای کنترل ترمینال**: کلیدهای `Ctrl+C` (لغو پروسه)، `Enter`، `Tab` (تکمیل خودکار)، `Up Arrow`، اعداد `1` تا `5`، `y`، `n`، پاکسازی و دانلود کامل لاگ
  - به‌روزرسانی زنده (Live Stream) متن خروجی با حفظ رنگ‌های ANSI
  - حفظ وضعیت پوشه کاری (`cd`)، متغیرهای محیطی و سابقه نشست
- 📄 **مدیریت هوشمند پیام‌های طولانی:**
  - شکستن خودکار خروجی‌های بیش از ۴۰۰۰ کاراکتر به چند پیام متوالی.
  - ارسال خروجی‌های بسیار بزرگ به صورت فایل متنی/مارک‌داون (`antigravity_response.md`).
- ⏳ **نشانگر تایپینگ (Typing Indicator):** ارسال مداوم علامت Typing در تلگرام هنگام پردازش پرامپت در سرور تا از فعال بودن ربات مطمئن شوید.

---

## 📋 نیازمندی‌ها

1. یک سرور مجازی لینوکس (VPS) که **Antigravity CLI (`agy`)** روی آن نصب و لاگین شده باشد.
2. **Docker** و **Docker Compose** روی سرور.
3. یک توکن ربات تلگرام از [BotFather](https://t.me/BotFather).

## 🛠️ مراحل راه‌اندازی گام به گام

### ۱. ساخت ربات در تلگرام
1. در تلگرام وارد ربات [@BotFather](https://t.me/BotFather) شوید.
2. دستور `/newbot` را ارسال کنید و نام و یوزرنیم ربات خود را مشخص کنید.
3. توکن ربات (مثلاً `123456789:ABCdefGh...`) را ذخیره کنید.

### ۲. دریافت شناسه عددی تلگرام (User ID)
برای امنیت کامل، باید شناسه کاربری خود را دریافت کرده و در ربات ست کنید تا اشخاص دیگر نتوانند از سرور شما سوء استفاده کنند:
- وارد ربات [@userinfobot](https://t.me/userinfobot) در تلگرام شوید و دستور `/start` را بزنید تا عدد `Id` شما را نمایش دهد (مثلاً `123456789`).

### ۳. بررسی کلید SSH روی سرور
اگر سرور شما کلید SSH محلی ندارد، با دستور زیر یک کلید بسازید و آن را مجاز کنید:
```bash
# ساخت کلید SSH در صورت عدم وجود:
ssh-keygen -t ed25519 -N "" -f ~/.ssh/id_rsa

# اضافه کردن کلید به authorized_keys:
cat ~/.ssh/id_rsa.pub >> ~/.ssh/authorized_keys
chmod 600 ~/.ssh/authorized_keys
```

### ۴. کپی و تنظیم پروژه روی سرور
پروژه را داخل سرور خود قرار دهید:
```bash
cd /مسیر/پروژه/telegram-agy-bot

# کپی فایل تنظیمات نمونه
cp .env.example .env
```

فایل `.env` را با یک ویرایشگر باز کنید (`nano .env`) و متغیرها را پر کنید:
```env
TELEGRAM_BOT_TOKEN=توکن_ربات_شما
ALLOWED_USER_IDS=شناسه_عددی_تلگرام_شما

# تنظیمات اتصال SSH به هاست
SSH_HOST=127.0.0.1
SSH_PORT=22
SSH_USER=root

# احراز هویت با کلید SSH
SSH_PRIVATE_KEY_PATH=/app/keys/id_rsa
SSH_LOCAL_KEY_PATH=/root/.ssh/id_rsa

# دایرکتوری پیش‌فرض پروژه شما
DEFAULT_WORK_DIR=/root/projects

# وضعیت پیش‌فرض پیام‌ها (continue یا new)
DEFAULT_MODE=continue

AGY_BIN_PATH=agy
```

> **نکته:** اگر می‌خواهید با رمز عبور SSH وصل شوید (به جای کلید SSH)، می‌توانید متغیر `SSH_PASSWORD=رمز_سرور` را مقداردهی کنید.

## 🚀 اجرا با داکر (Docker Compose)

برای ساخت ایمیج و اجرای کانتینر در پس‌زمینه، فقط کافیست دستور زیر را بزنید:
```bash
docker compose up -d --build
```

برای مشاهده لاگ‌های اجرای ربات:
```bash
docker compose logs -f
```

برای توقف ربات:
```bash
docker compose down
```

## 📱 نحوه استفاده در تلگرام

وارد ربات خود در تلگرام شوید و دکمه **Start** را بزنید:

| دستور | عملکرد |
|---|---|
| `/term` یا `/terminal` | ورود به ترمینال واقعی و تعاملی سرور (Live PTY Shell) |
| `متن دلخواه` (در حالت عادی) | اجرای پرامپت در Antigravity CLI طبق حالت فعلی (پیش‌فرض ادامه گفتگو) |
| `متن دلخواه` (در ترمینال) | ارسال مستقیم ورودی یا دستور به شل لینوکس یا اسکریپت در حال اجرا |
| `/new <prompt>` | شروع یک گفتگوی جدید بدون پیشینه قبلی (`agy -p`) |
| `/continue <prompt>` یا `/c <prompt>` | ادامه گفتگوی فعال فعلی (`agy -c -p`) |
| `/cd <مسیر>` | تغییر پوشه کاری (پروژه‌ای که Antigravity روی آن کار می‌کند) |
| `/pwd` | نمایش پوشه کاری فعلی |
| `/mode <new\|continue>` | تنظیم رفتار پیش‌فرض برای پیام‌های متنی عادی |
| `/sh <دستور>` | اجرای سریع یک دستور تکی لینوکس روی سرور |
| `/stop` یا `/kill` | توقف فوری پروسه‌های در حال اجرای Antigravity در صورت طولانی شدن یا انصراف |
| `/log` یا `/termlog` | دانلود خروجی کامل آخرین نشست ترمینال به صورت فایل متنی |
| `/status` | بررسی سلامت اتصال SSH، ترمینال و وضعیت نصب Antigravity CLI روی سرور |
| `/help` | نمایش راهنمای ربات |

### 🖥️ راهنمای کار با ترمینال واقعی تعاملی

وقتی دستور `/term` را ارسال می‌کنید:
1. یک نشست PTY واقعی لینوکس روی سرور باز می‌شود.
2. پنجره ترمینال به صورت زنده خروجی دستورات را نمایش می‌دهد.
3. می‌توانید هر اسکریپتی را اجرا کنید (مثلاً `./deploy.sh` یا `python3 app.py`).
4. **انتخاب گزینه‌ها در اسکریپت‌ها:**
   - اگر اسکریپتی از شما سوالی پرسید (مثلاً `Select option [1-3]:` یا `Do you want to continue? [y/N]`)، می‌توانید به سادگی دکمه‌های شیشه‌ای کیبورد (`1️⃣`, `2️⃣`, `3️⃣`, `👍 y`, `👎 n`) را لمس کنید یا مستقیماً پاسخ دلخواه خود را در تلگرام تایپ کرده و بفرستید!
   - اسکریپت پاسخ را از طریق stdin دریافت کرده و بدون معطلی به کار خود ادامه می‌دهد.
5. **کنترل‌های سریع کیبورد ترمینال:**
   - `🛑 Ctrl+C`: ارسال سیگنال وقفه (SIGINT) جهت متوقف کردن اسکریپت یا دستورات در حال اجرا
   - `⏎ Enter`: ارسال کلید Enter
   - `↹ Tab`: تکمیل خودکار نام فایل‌ها و دستورات شل
   - `⬆️ قبلی`: بازخوانی دستور قبلی
   - `🧹 پاکسازی`: پاک کردن صفحه ترمینال (`clear`)
   - `🔄 رفرش`: به‌روزرسانی فوری صفحه ترمینال
   - `📥 لاگ کامل`: دریافت کل سابقه خروجی‌ها در قالب یک فایل `.txt`
   - `❌ خروج`: بستن نشست ترمینال و بازگشت به حالت عادی Antigravity
6. **دستورات متنی داخل ترمینال:**
   - `/exit`: بستن نشست ترمینال
   - `/detach`: خارج شدن از حالت ترمینال بدون بستن پردازه‌های پس‌زمینه (می‌توانید با `/term` مجدداً به آن وصل شوید)
   - `/ctrlc`: ارسال Ctrl+C
   - `/log`: دریافت فایل لاگ

## 💡 نکات مهم

1. **دسترسی‌های ابزارها (`--dangerously-skip-permissions`):**
   هنگام اجرای غیرتعاملی پرامپت‌ها در سرور، ربات به صورت خودکار فلگ `--dangerously-skip-permissions` را اضافه می‌کند تا Antigravity نیازی به تأییدیه دستی در ترمینال نداشته باشد و بتواند فایل‌ها را تغییر داده یا ابزارها را اجرا کند.
2. **شبکه Host در داکر:**
   کانتینر از حالت `network_mode: "host"` استفاده می‌کند تا در لینوکس مستقیماً به پورت ۲۲ سرور متصل شود و هیچ سردرگمی بابت آی‌پی یا بریج داکر وجود نداشته باشد.
3. **سبک بودن برنامه:**
   این برنامه تنها با چند وابستگی بسیار سبک جاوا کامپایل شده، حجم فایل نهایی کمتر از ۱ مگابایت است و کمتر از ۵۰ مگابایت حافظه رم سرور را اشغال می‌کند.
